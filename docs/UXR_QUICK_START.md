## 💎 INSIGHTS CLÉS DE L'INTERVIEW #001

### ✅ Ce qui a été validé
- **Onboarding catastrophique** → Personne ne sait quoi faire
- **Questionnaire = killer** → Trop de friction avant la valeur
- **Besoin de guidage** → Propositions > champ libre

### ❌ Ce qui n'a PAS été testé
- Persona invalide (avait déjà des solutions efficaces)
- Beaucoup d'hypothèses n'ont pas pu être testées (bugs, persona)

### 🎯 Learnings méthodologiques
- **Creuser > Rebondir** : Utiliser les 5 pourquoi
- **Stories > Généralités** : Demander des exemples concrets
- **Recruter les bons personas** : Critères stricts essentiels

## 🎓 TECHNIQUES À MAÎTRISER

### Les 5 Pourquoi
```
"Pourquoi as-tu arrêté ?"
→ "Pourquoi... ?"
  → "Pourquoi... ?"
    → Continue jusqu'à la vraie raison
```

### Reformulation Miroir
```
Eux : "C'était pas pour moi"
Toi : "...pas pour moi ?"
Eux : [Développe]
```

### Le Silence
Après une question : **Compte jusqu'à 10** avant de relancer.

### Obtenir des Stories
❌ "Tu es stressé en général ?"  
✅ "Raconte-moi la dernière fois que tu t'es senti stressé. C'était quand exactement ?"
