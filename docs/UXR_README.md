# 📚 DOCUMENTATION UX RESEARCH - NEIJI

Bienvenue dans le framework complet de recherche UX pour Neiji.

---

## 📁 STRUCTURE DES DOCUMENTS

Voici tous les documents créés pour structurer ta recherche UX :

### 🎯 **1. UX_RESEARCH_FRAMEWORK.md** *(Document principal)*
**Quand l'utiliser :** Avant chaque interview

**Contenu :**
- Objectifs UXR globaux
- Définition du persona cible
- 8 hypothèses à valider avec critères
- Script d'interview complet (50 min)
- Techniques d'interview avancées
- Mindset et posture
- Checklist pré-interview
- Gestion après interview

**👉 C'est ton guide de référence, à relire avant chaque vague d'interviews.**

---

### 📊 **2. UXR_LEARNINGS_TRACKER.csv** *(Template Excel)*
**Quand l'utiliser :** Après chaque interview (dans les 24h)

**Contenu :**
- Tableau de tracking de tous les participants
- Colonnes pour chaque hypothèse
- Section insights inattendus
- Bugs/frictions observés
- Feature requests
- Pricing et NPS

**👉 Ouvre ce fichier dans Excel ou Google Sheets et remplis une ligne par interview.**

**Accès :** `/docs/UXR_LEARNINGS_TRACKER.csv`

---

### 📝 **3. INTERVIEW_001_SYNTHESE.md** *(Exemple de synthèse)*
**Quand l'utiliser :** Pour voir un exemple de synthèse complète

**Contenu :**
- Synthèse détaillée de ton interview avec Mathis
- Profil participant
- Insights stratégiques
- Problèmes UX observés
- Hypothèses validées/invalidées
- Actions produit prioritaires
- Learnings sur la méthodologie

**👉 Utilise ce format pour synthétiser chaque interview.**

---

### 🎯 **4. UXR_RECRUITMENT_GUIDE.md** *(Guide de recrutement)*
**Quand l'utiliser :** Quand tu cherches des participants

**Contenu :**
- Persona cible détaillé
- Critères d'inclusion/exclusion
- Questionnaire de screening (5 questions)
- Où recruter (6 méthodes)
- Compensation (options)
- Templates de messages
- Gestion des no-shows
- Tracking des participants

**👉 Utilise ce guide pour recruter 5-10 participants qui MATCHENT vraiment le persona.**

---

### ✅ **5. UXR_CHECKLIST_JOUR_J.md** *(Checklist rapide)*
**Quand l'utiliser :** Le jour de l'interview (à imprimer !)

**Contenu :**
- Checklist matériel
- Mindset à adopter
- Structure de l'interview (timing)
- Questions clés à ne pas oublier
- Techniques à appliquer
- Observations à noter
- Notes rapides pendant l'interview

**👉 Imprime ce document et garde-le sous les yeux pendant l'interview.**

**À imprimer :** Format A4, recto-verso

## 🚀 WORKFLOW COMPLET

Voici comment utiliser tous ces documents ensemble :

### **PHASE 1 : PRÉPARATION (Semaine 1)**

**Jour 1-2 : Comprendre le framework**
- [ ] Lire `UX_RESEARCH_FRAMEWORK.md` en entier
- [ ] Comprendre les 8 hypothèses à valider
- [ ] Se familiariser avec le script d'interview

**Jour 3-5 : Recruter des participants**
- [ ] Ouvrir `UXR_RECRUITMENT_GUIDE.md`
- [ ] Préparer le questionnaire de screening
- [ ] Poster sur Instagram, Reddit, réseau...
- [ ] Screener les candidats
- [ ] Confirmer 5-7 interviews

**Jour 6-7 : Préparation technique**
- [ ] Fixer l'onboarding du produit (PRIORITÉ)
- [ ] Supprimer le questionnaire initial
- [ ] Tester le produit soi-même
- [ ] Préparer l'enregistrement audio/vidéo
- [ ] Ouvrir `UXR_LEARNINGS_TRACKER.csv`

---

### **PHASE 2 : INTERVIEWS (Semaine 2)**

**1h Avant Chaque Interview**
- [ ] Relire `UX_RESEARCH_FRAMEWORK.md` (script)
- [ ] Imprimer `UXR_CHECKLIST_JOUR_J.md`
- [ ] Préparer matériel (enregistreur, laptop, notes)
- [ ] Ouvrir Neiji sur landing page
- [ ] Mindset : Curiosité totale

**Pendant l'Interview (50 min)**
- [ ] Suivre la structure de la checklist
- [ ] Prendre notes minimales (focus sur l'écoute)
- [ ] Enregistrer pour transcription IA après
- [ ] Observer les réactions non-verbales

**Juste Après l'Interview (10 min)**
- [ ] Noter 3 insights principaux à chaud
- [ ] Noter 1 chose surprenante
- [ ] Sauvegarder l'enregistrement
- [ ] Envoyer remerciements + compensation

---

### **PHASE 3 : ANALYSE (Après chaque interview)**

**Dans les 24h**
- [ ] Réécouter avec transcription IA (Otter, Fireflies...)
- [ ] Remplir une ligne dans `UXR_LEARNINGS_TRACKER.csv`
- [ ] Créer une synthèse (utiliser `INTERVIEW_001_SYNTHESE.md` comme template)
- [ ] Identifier 3-5 insights clés
- [ ] Lister bugs/frictions UX observés

**Après 5 Interviews**
- [ ] Analyser les patterns dans le Excel
- [ ] Compter combien d'hypothèses validées/invalidées
- [ ] Prioriser les actions produit
- [ ] Décider si besoin de plus d'interviews ou si patterns clairs

## 🎯 RAPPELS IMPORTANTS

### ✅ À FAIRE

**Avant les interviews :**
- Recruter les BONS personas (pas comme Mathis)
- Fixer l'onboarding du produit
- Préparer l'enregistrement

**Pendant les interviews :**
- CREUSER avec les 5 pourquoi
- Obtenir des STORIES concrètes, pas des généralités
- Rester NEUTRE même si critiqué
- Laisser des SILENCES

**Après les interviews :**
- Remplir le Excel dans les 24h
- Chercher les PATTERNS récurrents
- Prioriser les actions produit

---

### ❌ À ÉVITER

**Recrutement :**
- ❌ Personnes qui ont déjà des solutions efficaces
- ❌ Experts en méditation
- ❌ Gens dans la tech/product (trop "meta")

**Pendant l'interview :**
- ❌ Défendre ton produit
- ❌ Poser des questions orientées
- ❌ Rebondir sans creuser
- ❌ Expliquer comment ça marche (sauf si bloqué)

**Analyse :**
- ❌ Tirer des conclusions sur 1 seul interview
- ❌ Ne voir que ce qui confirme tes croyances
- ❌ Ignorer les insights négatifs

## 📊 MÉTRIQUES DE SUCCÈS

Tu sauras que ta recherche UX est réussie si :

✅ **Après 5 interviews, tu peux répondre :**
- Le problème existe-t-il vraiment ? (H1)
- Les solutions actuelles sont-elles insuffisantes ? (H2)
- La personnalisation vaut-elle l'attente ? (H3)
- Méditation seule suffit ou élargir ? (H4)
- Chat ou paramètres ? (H5)
- Neiji comme mascot marche ? (H6)
- L'onboarding bloque-t-il ? (H7)
- Quand l'utilisent-ils ? (H8)

✅ **Tu as identifié :**
- 3-5 patterns récurrents
- Top 3 bugs/frictions UX
- Top 3 feature requests
- Range de pricing acceptable
- NPS moyen

✅ **Tu peux prioriser :**
- Quelles hypothèses valider/invalider
- Quelles actions produit en priorité
- Quel positionnement adopter

## 🛠️ ACTIONS PRODUIT PRIORITAIRES (Basées sur Interview 001)

### 🔴 **CRITIQUE (à faire AVANT les prochains interviews)**

1. **Onboarding avec propositions guidées**
   - Version Quick Start avec 4 boutons (matin, focus, calme, sommeil)
   - OU version conversationnelle (étapes guidées)

2. **Supprimer le questionnaire initial**
   - Laisser générer sans friction
   - Apprendre passivement les préférences

3. **Rendre le mode meditation discoverable**
   - Tooltip au premier chargement
   - État vide du chat plus explicite

### 🟡 **IMPORTANT (court terme)**

4. **Clarifier la landing page**
   - Value prop en 5 secondes
   - Hero copy plus clair

5. **Améliorer le feedback pendant génération**
   - Animation de breathing
   - Ou mini-exercise pendant l'attente

### 🟢 **À EXPLORER (long terme)**

6. **Réduire temps de génération à <30 sec**
   - Optimisation technique
   - Architecture backend

7. **Explorer "méditation comme état"**
   - Autres formes de mindfulness
   - Breathing, body scan, grounding...
